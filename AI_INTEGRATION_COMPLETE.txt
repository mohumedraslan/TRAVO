3. ASSISTANT ENDPOINT - /api/assistant/ask
====================================================================

Location: travo/backend/services/assistant_service/routes.py

Request Format:
{
  "query": "Your question here",
  "location": "Optional location context",
  "query_type": "TEXT" or "IMAGE",
  "image": "Base64 encoded image (required for IMAGE type)"
}

TEXT Query Flow:
1. Receives text question
2. Calls DeepSeek API with context
3. Returns conversational response

IMAGE Query Flow:
1. Receives base64 image
2. Calls Google Vision API for landmark detection
3. If landmark detected:
   - Sends landmark name + user question to DeepSeek
   - Returns detailed information
4. If no landmark:
   - Uses label detection
   - Sends labels + user question to DeepSeek

Response Format:
{
  "type": "TEXT" or "IMAGE",
  "original_query": "...",
  "landmark_detected": "..." (IMAGE only),
  "confidence": 0.95 (IMAGE only),
  "deepseek_response": "...",
  "location": "..."
}

14. TROUBLESHOOTING
====================================================================

If DeepSeek API fails:
- Check API key in config.env
- Verify network connectivity
- Check Huawei Cloud API status
- Review logs for error messages

If Google Vision fails:
- Verify credentials file path
- Check service account permissions
- Ensure Vision API is enabled in Google Cloud
- Review IAM roles

If endpoint returns 422:
- Check JSON structure (flat, not nested)
- Verify all required fields present
- Check Content-Type header
