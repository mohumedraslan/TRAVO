# TRAVO Project Onboarding

Welcome to the TRAVO project! This document provides an overview of the architecture, technology stack, and setup instructions to get you started quickly.

## 1. Project Overview
TRAVO is an AI-powered travel assistant application that helps users discover monuments, plan trips, and get personalized itineraries.
**Key Features:**
- **Monument Identification:** Users can take a photo of a monument, and the app identifies it using AI (CLIP model).
- **Personalized Itineraries:** Generates travel plans based on user interests and identified locations.
- **Interactive Map:** View monuments on a map and add them to itineraries.
- **User Accounts:** Save favorites, preferences, and trip history.

## 2. Technology Stack

### Mobile App (`trovaMobile`)
- **Framework:** React Native with Expo (Managed Workflow).
- **Navigation:** Expo Router (File-based routing).
- **State/Data:** React Context, Supabase Client.
- **Maps:** `react-native-maps` (Google Maps provider).
- **Analytics:** Sentry (Error Tracking), PostHog (Event Tracking).
- **Styling:** `StyleSheet` with a custom theme system.

### Backend (`travo/backend`)
- **Framework:** FastAPI (Python).
- **AI/ML:** PyTorch, Transformers (Hugging Face), CLIP Model for image recognition.
- **Database:** Supabase (PostgreSQL) for user data; Local JSON (`monuments.json`) for static monument data.
- **API:** RESTful endpoints for vision, itinerary generation, and chat.

### Infrastructure
- **Database & Auth:** Supabase.
- **Storage:** Supabase Storage (for user uploads/avatars).

## 4. Setup Instructions

### Prerequisites
- Node.js (v18+) & npm/yarn
- Python (v3.10+)
- Expo Go app on your physical device (or Android Emulator/iOS Simulator)

### Backend Setup
1.  Navigate to the backend directory:
    ```bash
    cd travo/backend
    ```
2.  Create a virtual environment:
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # Windows: .venv\Scripts\activate
    ```
3.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
4.  Start the server:
    ```bash
    uvicorn main:app --reload --host 0.0.0.0 --port 8000
    ```
    *Note: Ensure your mobile device is on the same network if testing on a physical device.*

### Mobile App Setup
1.  Navigate to the mobile directory:
    ```bash
    cd trovaMobile
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the Expo development server:
    ```bash
    npx expo start
    ```
4.  Scan the QR code with Expo Go (Android) or Camera app (iOS).

## 5. Key Workflows

### Monument Identification
- **Frontend:** `CameraScreen` captures image -> sends Base64 to backend.
- **Backend:** `vision_service` receives image -> processes with CLIP -> matches against `monuments.json` -> returns match.

### Itinerary Generation
- **Frontend:** `PlanItineraryScreen` collects user preferences -> calls backend.
- **Backend:** `itinerary_service` uses logic/AI to create a day-by-day plan -> returns JSON.

### Map View
- **Frontend:** `MapScreen` renders `MapView` -> fetches monuments -> displays Markers.
- **Web Fallback:** `MapScreen.web.tsx` handles web compatibility by showing a fallback UI.

## 7. Troubleshooting
- **"Unknown" Monument:** Check backend logs. Ensure `monuments.json` is valid and loaded.
- **Network Error:** Verify backend IP address in `src/config/api.ts` (or wherever configured) matches your machine's local IP.
- **Web Build Error:** `react-native-maps` is not supported on web. Use `MapScreen.web.tsx` for web-specific logic.
